## 浏览词库、释义词云和管理单词

- **词库浏览**：可选 A–Z 或考频从高到低；未标记考频的词排在后面。支持英文 / 中文搜索、首字母筛选、分页。点击英文查看完整释义、原 PDF 页码和考频，并可前后翻词。
- **释义词云**：释义越常见，字号越大。默认显示对应多个单词的释义，可切换显示全部。点击释义即可查看对应单词、匹配的义项及完整释义，也可直接练习这一组词。
- 词云按中文义项和预设近义词组归类，例如“阻止 / 妨碍”。它是辅助比较的规则归组，**不是完整的语义词典；同组词不代表所有语境都能互换**。可通过搜索和自定义标签补充查找。
- **新增单词**：填写英文及释义，可选考频和释义标签。新词保存后即可参与浏览、词云和两种练习；同名词不允许重复添加。
- **删除和恢复**：删除只影响自己的词库，单词退出练习和词云；在“已删除”中可恢复。原有答题和错误历史保留，恢复后仍可查看。共享 PDF 原始词库不会被修改。
- 登录后，新增 / 删除 / 恢复会随当前账号同步到其他设备；访客模式先保存在本机。

## 怎么练习

### 释义四选一

显示一个英文词，从 4 条不同释义中选择。每题恰有一个正确选项；干扰项来自整个真实词库。答案提交后锁定本题，显示正确释义与误选项对应的英文词，点击“下一个单词”继续。

- 可选全词库、待复习错词、未学词，以及首字母。
- 每轮 10 / 20 / 30 / 50 题；不足时按实际数量出题。
- 支持随机、A–Z 顺序和高频优先。
- 电脑键盘：1–4 选择，Enter 下一题。

### 单词释义连连看

每组最多 5 对，单词和释义分别打乱。点左侧单词、右侧释义即可配对，也可以先点释义。配对成功会显示连线；配错时会把**当前选中的英文单词**加入错题本，并允许重试。词不足时仍支持小组练习。

### 错题本

- 两种练习的错误都会自动保存，记录错误次数。
- 支持搜索、首字母筛选、待复习 / 已掌握 / 全部错词。
- 点“重练这些词”开始四选一复习；也可在连连看里选“仅待复习错词”。
- 记熟后点“标为已掌握”，它会移出待复习列表，历史记录仍保留。
- 已掌握的词再次答错，会自动回到待复习。

## 访客、登录和离线记录

- 未登录：记录保存在当前浏览器本机。访客记录不会自动跨设备。
- 登录后：只加载当前账号的数据。自动同步，也可以点击页顶同步状态或账号内“立即同步”。
- 登录后点账号内 **导入这台设备的访客练习记录**，可将之前的本机记录、自定义词和删除 / 恢复记录并入账号。每条记录有唯一标识，重复同步 / 导入同一备份不会重复计数。
- 页面已经打开并加载词库时，断网仍能答题，记录进入本机待同步队列；恢复网络会重试。**这不是完整的离线安装应用，首次加载或刷新网页需要网络。**
- 可在账号面板或词库页导出 JSON 学习记录备份，并在账号面板导入。v2 备份同时包含自定义词与词库变更，仍可导入 v1 学习记录备份。备份不包含密码或登录令牌。
- 退出登录后显示访客记录，不会把前一个账号的数据混进访客记录。
- 浏览器无痕模式、清除网站数据或本机空间不足会影响本机保留；未同步前可先导出备份。同步状态会显示失败或待同步情况。

## 数据库内容

项目：`english-words`，区域：东京。表如下：

| 表 | 内容 | 权限 |
| --- | --- | --- |
| `public.vocab_words` | 760 个词及其完整释义、词频、原 PDF 页码 | 所有人可读，浏览器不可修改 |
| `public.vocab_events` | 答题、错误、掌握与恢复复习事件 | 登录用户只能读 / 新增自己的记录 |
| `public.vocab_catalog_events` | 自定义词、个人删除 / 恢复事件 | 登录用户只能读 / 新增自己的记录 |

数据库已开启行级权限 RLS。事件只追加，不覆盖其他设备的历史；按 `(user_id, id)` 去重，支持重试和多设备合并。错题状态和个人词库由事件顺序计算。同步先提交自定义词，再提交相关答题。不同账号的数据互相隔离。

`config.js` 中的 publishable key 是浏览器公开连接参数，个人数据访问由登录身份和数据库权限控制。**不要把 service_role 或 secret key 放进网页。**

若将来需要搬到其他 Supabase 项目：

1. 在新项目 SQL Editor 执行一次 `database/schema.sql`（仅用于全新项目）。
2. 执行 `database/seed.sql` 导入词库。
3. 修改 `config.js` 中的 URL 和 publishable key。
4. 配置新项目的邮件返回网址。

目前项目已经完成上述数据库初始化，不需要再运行。请保留新项目自己的数据，不要把初始化脚本重复应用到已修改的表结构。

## 文件说明

- `index.html`：网页入口。
- `styles.css`：电脑、手机响应式样式。
- `app.js`：四选一、连连看、错题本、词库搜索与账号交互。
- `library.js`：词库列表、完整释义、词云及新增 / 删除 / 恢复界面。
- `catalog.js`：词库事件合并、字段校验与排序。
- `semantics.js`：义项提取与近义词组归类。
- `core.js`：出题、记录去重、错题统计。
- `store.js`：账号数据隔离、本机记录、离线队列与数据库同步。
- `words.json`：来自 PDF 的完整词库，含原页码，后续可以扩充。
- `assets/supabase-2.118.0.js`：固定版本的本地 SDK，无需浏览器连接第三方 CDN。
- `database/`：完整 v2 初始化与原始词库导入 SQL；`upgrade-v2.sql` 仅供尚未升级的其他 v1 数据库使用，本项目已执行。
- `tests/`：核心逻辑测试；开发者可执行 `npm test`。

应用没有付费依赖。数据库和托管的实际用量、免费额度及账单，以你自己的 Supabase / GitHub 账户控制台为准。
